# Osito Plan

Plan personal en el navegador: **tareas** (con fecha y urgencia), **rutina diaria**, **metas** del mes y del año,
**notas**, **horario semanal** de lunes a domingo en bloques de 30 minutos (con varios horarios guardados) y **dinero**
(presupuesto del mes por % o monto fijo, y el ahorro mes a mes del año).

- Sin servidor ni cuentas: los datos se guardan en el `localStorage` de tu navegador y **no salen de tu equipo**.
- **Respaldar** descarga un archivo con todo; **Importar** lo restaura (también acepta el archivo de la herramienta anterior «Mi semana»).
- HTML, CSS y JavaScript sin dependencias ni compilación. Para probarlo en local:

```sh
python3 -m http.server 4800 --bind 127.0.0.1
# abre http://127.0.0.1:4800/
```
